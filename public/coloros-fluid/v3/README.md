# 第三版：透明冰层与流动

第二版保留在上级目录，第三版独立存放，不覆盖第二版图像、生成器或着色器。

- 移除第二版中等尺度的颗粒纹理；仅保留低强度细颗粒，约为原动态纹理幅度的四分之一。
- 曲面的透明层有变化的厚度：取样位置按表面方向偏移，形成透射背景的折射；轻微 RGB 偏移表达色散。
- 边缘用较暗内侧、低强度外侧反光和宽散射组合，避免高亮自发光线条。
- 动画时间系数从 .045 增至 .24，默认速度从 .65 增至 1，约为第二版默认速度的 8.2 倍。
- 采用风格化材质表达，并非物理光线追踪。

`fluid-python.png` 是 3840 × 2160 静态背景；`generate.py` 为对应 Python 生成器。
`index.html` 提供 p5.js 动态预览、暂停、速度调节、PNG 导出，以及返回第二版的链接。

生成其他动画时刻：`python3 generate.py --time 2`。
