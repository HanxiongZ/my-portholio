# ColorOS fluid · 第二版

原创程序化背景，无外部图像输入。主色 #0066FF；邻近冰青与蓝紫，浅蓝白表达水雾。
以不对称、宽窄渐变的有机曲面表达水，低对比的透明肩部表达冰的透光，柔和浅色表达气态水。移除发光轮廓，叠加细颗粒与较宽的微纹理。动态纹理固定，避免闪烁。
这是视觉抽象，不是物理流体或光线追踪模拟。

## 交付
- `fluid-python.png`：3840 × 2160，适合 Figma 叠加界面。
- `generate.py`：Python / NumPy / Pillow 静态生成器，`--time` 可生成其他流动相位。
- `index.html` + `sketch.js` + `fluid.frag` + `fluid.vert`：p5.js / WebGL 动态背景。
- `vendor/p5.min.js`：p5.js 1.11.11，本地依赖，不依赖线上 CDN。

## 预览
从此目录运行 `python3 -m http.server 8766 --bind 127.0.0.1`，浏览器打开 http://127.0.0.1:8766。
动态版默认 30 fps，慢速流动；支持暂停、调速度、导出当前 PNG。按 H 隐藏工具栏。
系统开启减少动态效果时默认暂停。浏览器窗口改变时重新适配画布。
网页集成时移除预览工具栏，把 #motion 放在页面底层，界面置于上层。

## 重新生成
安装 NumPy / Pillow 后：
`python3 generate.py --width 3840 --height 2160 --time 0`
这里 --time 与动态版的动画时间对应，默认相位为 0。

本轮只创建独立背景资产，未改动作品集现有页面。

第二版微调：两层颗粒强度均乘以 0.75，即减少 25%；形状、配色、颗粒尺度与动画速度保持不变。
