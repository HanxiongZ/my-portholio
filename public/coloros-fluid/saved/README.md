# ColorOS 项目背景 · 暂存定稿

用户选择第二版的形状与配色，颗粒强度降低 25%。保留原有颗粒尺度。
默认动画速度为 2.25，即旧滑块最大速度 1.5 的 1.5 倍；时间系数为 0.045。

## 文件
- `index.html`：本地动态预览，可暂停、调速度与导出 PNG。
- `sketch.js`、`fluid.frag`、`fluid.vert`：动态背景源码。
- `vendor/p5.min.js`：本地 p5.js 依赖。
- `fluid-python.png`：3840 × 2160 静态底图，可作网页加载占位与静态替代。
- `generate.py`：静态图生成器。
- `settings.json`：选定参数。
